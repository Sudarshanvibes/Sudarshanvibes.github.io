# Sudarshanvibes.github.io

Personal portfolio website featuring a text-to-video generation model.

## Features

- **Portfolio Homepage**: Introduction and about section
- **Text-to-Video Generator**: Interactive tool for creating videos from text descriptions
  - Multiple video styles (Realistic, Animated, Cinematic, Abstract)
  - Customizable duration and quality settings
  - Real-time canvas-based animation
  - Download capability
